Clean Updates

Official first-party release centre · Arise 0.2

Arise 0.2 rules

Clean launches and works locally without any third-party API key. When you deliberately connect to an external provider, Clean asks for that provider's key at that moment. The key is session-only by default and is not saved to Clean storage unless you explicitly choose otherwise in a future release.

The iPhone build keeps Brain, Projects, The Vault and More, with Settings and Check for Updates. Arise 0.2 adds a visible Download / Update Clean control and a Download Arise 0.2 button.
