Install

  1. Download PetsOS-11.1.zip and open it.
  2. Mac (Apple silicon): open the “Mac (Apple silicon)” folder and double-click “Start Pets OS.command”. The first time, right-click it and choose Open (or System Settings › Privacy & Security › Open Anyway).
  3. Pets OS starts in a window and sets itself up on its first start. Shut it down from its own menu.
  4. PC (Intel or AMD): write “PetsOS-11.1-PC-USB.img” to a USB stick (balenaEtcher works) and start the PC from it in the UEFI boot menu. Writing it erases the stick.

Known limitations

  • Developer preview: on a Mac it runs in a window (a virtual machine); on a PC it starts from the USB stick and leaves the PC's own disk alone. Try it on a spare PC first.
  • The phone edition is a separate download: Pets OS for Stephone on the Android page.
