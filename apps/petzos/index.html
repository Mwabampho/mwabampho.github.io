Pets OS for Frientom

A new operating system created by Fionn Mpho Mwaba. Made for Frientom, the official Pets OS laptop (coming soon), and for Mac, Linux and PC.

PetsOS is an independently developed operating-system project within the ShouldBe ecosystem, designed around its own interface, application navigation and built-in assistant, Clarice.

It is written from scratch, with its own kernel, filesystem, app model and desktop, and starts by itself from a UEFI disk on Intel/AMD PCs and 64-bit ARM. So far it has been tested in virtual machines, not yet on a real PC.

What this build does

Storage that survives a restart

PetsFS, a copy-on-write filesystem on a virtual disk, keeps your files when PetsOS shuts down and starts again.

Real programs, kept apart

Apps run in user mode with their own memory, a preemptive scheduler and a system-call interface, so one app can’t overwrite another.

Apps with permissions

Each app is installed from a .pet package checked with SHA-256, lives in its own folder, and only gets the permissions you switch on.

O Store

The built-in store installs, updates, opens and removes apps. Speco, Ganise Organize and Should Be pass their tests in this build.

Desktop, dock and windows

A full graphical desktop with a dock, launcher and windows for every app, driven by keyboard and pointer.

Its own internet connection

PetsOS reaches the web by itself: its own DHCP, DNS, TCP and encrypted HTTPS (TLS) with certificate checks. No helper on the Mac is involved.

Starts like an operating system

PetsOS 11 is a bootable disk image: UEFI firmware starts the PetsOS boot loader, which starts PetsOS. On first start it sets up its own disk and installs its apps.

Rest, Clarice and the PetsOS look

Rest

In this build

The app drawer and file navigator: a person sitting at a desk in the corner of the desktop. Click to browse your files; press and hold and Rest glows and offers your favourite apps and the heart, for daily activities.

Clarice

In this build

The ShouldBe assistant, as an app in PetsOS. She is the same Clarice that runs on the owner’s Mac, reached through the PetsOS helper; from PetsOS she can chat but can’t act on the Mac.

Where it has been tested

  • ✓ The PetsOS 11 disk image booted by UEFI firmware (edk2) in QEMU 11.1.1’s “virt” machine with Apple Hypervisor acceleration, on a MacBook Pro (Mac17,2) running macOS 26.6.1
  • ✓ The download’s own start script and bundled QEMU on the same Mac, with Homebrew blocked, as on a Mac with nothing installed
  • ✓ The same image in full emulation (Cortex-A72, GICv2 interrupt controller), on the same Mac

Known limitations

  • PetsOS boots from its own disk image, but only inside a virtual machine. It has drivers for QEMU’s “virt” machine only, so it does not start directly on a Mac, a PC or any other hardware yet.
  • There is no installer. PetsOS is never installed onto your Mac’s disk and never replaces macOS.
  • Native Apple silicon support is not ready. The drivers a MacBook needs (storage, keyboard, trackpad, USB, display, Wi-Fi, power) are not written yet, and early boot experiments have not been run on hardware.
  • The Claude app needs your own Claude API key (typed into PetsOS’s Terminal with claude-key). Clarice is not part of the public download.
  • Video and camera are not available to apps yet.
  • The download is not signed with an Apple Developer ID, so macOS asks once before opening it.
