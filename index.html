Getting an app

  1. 1. Pick an app

    Every app has a short description and says whether it works on its own.

  2. 2. Download it

    Each download is a zipped Mac app with a checksum, so you can check it arrived intact.

  3. 3. Open it

    The first time, allow it in System Settings → Privacy & Security → Open Anyway. The apps aren't notarised by Apple yet.
